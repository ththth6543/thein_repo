맥(Mac) 환경에서 이클립스(Eclipse)를 사용할 때 가장 헷갈리는 점은 윈도우의 `Ctrl` 키 역할이 대부분 **`Cmd(⌘)`** 키로 바뀌거나, 일부 기능은 **`Option(⌥)`** 또는 **`Control(⌃)`** 키 조합으로 복잡하게 맵핑되어 있다는 점입니다.


## 1. 코드 작성 및 편집 (가장 많이 씀)

| 기능 | 맥 단축키 | 비고 |
| --- | --- | --- |
| **자동 완성 (Content Assist)** | **`Option(⌥) + Space`** | 맥 기본 단축키(Spotlight)와 겹치므로 아래 주의사항 확인 필수! |
| **빠른 수정 (Quick Fix)** | **`Cmd(⌘) + 1`** | 에러나 경고창이 떴을 때 해결책 제시 |
| 한 줄 지우기 (Delete Line) | `Cmd(⌘) + D` |  |
| 한 줄 복사 (Duplicate Line) | `Cmd(⌘) + Option(⌥) + ↓ / ↑` |  |
| 줄 이동 (Move Line) | `Option(⌥) + ↓ / ↑` | 현재 줄의 코드를 위아래로 이동 |
| 코드 블록 주석 처리 | `Cmd(⌘) + /` | 한 줄 혹은 블록 전체 토글 주석 |
| 블록 주석 제거/추가 | `Cmd(⌘) + Control(⌃) + /` | `/* */` 주석 처리 |
| **코드 자동 정렬 (Format)** | **`Cmd(⌘) + Shift + F`** | 들여쓰기 및 코드 포맷팅 깔끔하게 정리 |

## 2. 코드 이동 및 찾기 (내비게이션)

| 기능 | 맥 단축키 | 비고 |
| --- | --- | --- |
| **클래스/메서드 선언부 이동** | **`Cmd(⌘) + 클릭`** 또는 **`F3`** | 정의된 곳으로 워프 |
| 이전 작업 위치로 돌아가기 | `Cmd(⌘) + Option(⌥) + ← / →` | 코드 보다가 직전 위치로 복귀 |
| 파일 내에서 검색 / 바꾸기 | `Cmd(⌘) + F` |  |
| **전체 프로젝트에서 검색** | **`Cmd(⌘) + H`** | File Search 탭 활용 |
| 특정 파일(클래스) 열기 | `Cmd(⌘) + Shift + R` | 파일명으로 빠르게 찾기 |
| 파일 내 구조 보기 (Outline) | `Cmd(⌘) + O` | 변수나 메서드 목록 팝업 |

## ⚠️ 맥 사용자 필수 체크: `Option + Space` 충돌 해결법

맥에서 이클립스 자동 완성 단축키인 `Option(⌥) + Space`를 누르면 이클립스 창이 아니라 맥 자체의 Spotlight(검색창)이 켜지는 경우가 많습니다. 시스템 단축키가 선점했기 때문인데요, 이를 해결하는 방법은 두 가지가 있습니다.

### 방법 A: 맥 시스템 단축키 해제 (추천)

1. 맥 좌측 상단 사과 로각 클릭 $\rightarrow$ 시스템 설정(System Settings)으로 이동합니다.
2. **키보드(Keyboard)** $\rightarrow$ **키보드 단축키(Keyboard Shortcuts...)** 버튼을 누릅니다.
3. **Spotlight** 메뉴를 선택합니다.
4. `Spotlight 검색 창 보기` 옆에 켜져 있는 체크박스를 해제하거나 단축키를 다른 것으로 변경합니다.

### 방법 B: 이클립스 내부 단축키를 윈도우처럼 바꾸기

1. 이클립스 상단 메뉴 `Eclipse` $\rightarrow$ `Settings...` (단축키 `Cmd(⌘) + ,`)를 엽니다.
2. 왼쪽 검색창에 **Keys**를 입력하고 선택합니다.
3. `Content Assist`를 찾아서 하단의 Binding을 윈도우와 같은 `Ctrl + Space`로 변경하고 `Apply`를 누릅니다.
